# Regizor 360

Editor pentru filmările și pozele Insta360 (X5, ONE X2), care rulează direct pe telefon:
citește fișierele de pe card, lipește cele două lentile în 360, îndreaptă orizontul cu giroscopul,
urmărește persoana aleasă și exportă video MP4 (cu sunet) sau poze.

**Descărcare:** secțiunea *Releases* din dreapta → `Regizor360.apk`.

Aplicația se construiește automat la fiecare modificare (GitHub Actions).
